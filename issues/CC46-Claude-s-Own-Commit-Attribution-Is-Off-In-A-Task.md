# CC46 — Claude's Own Commit Attribution Is Off In A Task

**Status:** Idea.

**What must be true.** A commit or a pull request Claude Code writes in a Porelo task carries none of Claude Code's own
attribution, no `Co-Authored-By:` line and no generated-with note, so the project's own trailer rule holds without the
task's context having to overrule Claude's default; the settings file the adapter writes switches it off.
